# Vice Evidence

Costa Luma Central Blotter does not investigate. They crop.

**Whoever fills the frame did it.**

A micro-experience for the Unlayer Build With Image Editor Challenge. Unlayer's React Image Editor is the accusation: your crop becomes the wanted poster.

## Play

```bash
npm install
npm run dev
```

Start shift → pick a still (try **Seagull Congress**) → crop → title the exhibit → it drops into the case file.

Each extra proof is a **separate picture** stacked down the dossier. Print opens the printer on the case file as you see it.

Tight crop → **WANTED**. Whole photo → **DENIED**.

## How the editor is used

Crop is the mechanic. Text, draw, stickers, filters, and frames still work; the department only really trusts how much of the JPEG you left in the frame.
